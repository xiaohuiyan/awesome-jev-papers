- Swept arXiv for first submissions from 2026-10-27 through 2026-10-30 with the four standing API queries ("Jev", "System One", "typed decision", "decision model") and added **9 papers**, several first submitted 10-27/10-28 but indexed only after the 2026-10-29 sweep ran.
